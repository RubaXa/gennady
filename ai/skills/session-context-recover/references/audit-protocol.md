# Audit protocol

Run three independent roles over the same bounded evidence pack. Give each role only its assignment; do not prime it with the expected conclusion.

## Intent & Timeline

Return goals, requirement changes, operator corrections, explicit decisions, open questions, and the last accepted plan. Separate operator intent from assistant interpretation.

## Execution & State

Return concrete actions, edited paths, commands, tests, failures, commits, working directory, branch, and last confirmed action. Distinguish attempted, observed, and completed work.

## Adversarial Audit

Seek counterevidence. Check completion claims against tests and tool results, later reversals against earlier decisions, ignored operator requirements, interrupted calls, stale workspace assumptions, and missing evidence. Provide a verification action for every disputed or high-impact unknown claim.

## Reconciliation

The primary agent merges reports by evidence strength, not majority vote. If agents disagree, inspect the cited records or current workspace. Keep unresolved conflicts visible for the operator.
