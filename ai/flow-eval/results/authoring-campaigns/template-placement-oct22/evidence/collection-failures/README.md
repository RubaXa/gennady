Existing receipts are never overwritten; primary summary/trajectory hashes must still match before reuse.

This is NOT a full causal transcript. `complete: true` means every selected archived public tool ID was found and validated, not that opaque Bash internals or arbitrary output were captured. Opaque parts remain separately labelled `opaque-command-output-not-read`, with no output access. Direct and cd-only target checks are distinguished. `shellExit` for opaque calls is not proof of embedded command success.

Each receipt binds source commit, summary/trajectory SHA, scenario, task/oracle/harness digests, exact archived session/call IDs, SDK model and start/end timestamps. Only exact target `sdd-check --spec … --authoring` output is read. Diagnostic text is sanitized and limited to 1024 UTF-8 bytes TOTAL per result. Public SDK call identity/models/timestamps are retained; private reasoning/text parts and arbitrary Bash outputs are not inspected or exported. No model calls are made.
