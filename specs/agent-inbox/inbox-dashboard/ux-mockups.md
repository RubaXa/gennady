```
│       👤  mail/messenger!172   author     ▶ синтез, 04:12      │
│       👤  mail/messenger!174   author     ⏸ ждёт моего решения │
│  ○  Подготовка окружения (фон, не блокирует): worktree 1/3     │
```

Правила: доска закрыта до `ready` (read-only по кнопке); падение фазы = ❌ + retry
(не вечный ⏳); worktree — не фаза.

## 5. Виджет «Находки» (группа, циклический)

```
┌─ 🔍 НАХОДКИ (4) · REQUEST_CHANGES ────────────────────────────────┐
│ фактчек 3/4 · углублено 1 · совпадений с чужими тредами: 1        │

│ 🔴 #1 Ретрай без джиттера · retry.ts:118            ✔ проверена   │
│    ▸ diff-note: 12 строк контекста                    [развернуть]│
│    [📮] [✏️ править] [🗑] [🔎 углубить] [🌐 вширь]                 │
│ 🟡 #2 Нет метрики на флуд · queue.ts:88              ✔ проверена   │
│ ⚡ #3 Тред @rev2 отвечен, но есть инсайт                          │
│    [👍+💬 запостить инсайт]                                        │
│ 🤝 #4 = треду @rev1 (уже 👍) → в «скрытые»              [скрыть]  │
│ ───────────────────────────────────────────────────────────────── │
│ [📮 Постить выбранные (3)] [✅ Фактчек всех] [🌐 Вширь по паттерну]│
│ Скрытые (2) ▸                                                     │
└────────────────────────────────────────────────────────────────────┘
```

После постинга: виджет тонет; при новых находках всплывает — внутри ТОЛЬКО новые
(обработанные — в истории виджета).

```

   🤖 auto  [↩ отменить]     ← при auto-mode: компенсирующий эффект
```

Resolved → тонет навсегда; новое действие = новый пост.
