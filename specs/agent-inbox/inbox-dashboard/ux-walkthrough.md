## Экран 1. Доска (`#/`)

### 1.1 Хром

| Элемент              | Вижу                  | Состояния                                                 | Взаимодействие          |
| -------------------- | --------------------- | --------------------------------------------------------- | ----------------------- |

| «обновлено Nс назад» | возраст снимка        | 🟢 тикает                                                 | —                       |

### 1.2 Группы внимания

| Группа                | Когда МР здесь                          | Особенности                                                                          |
| --------------------- | --------------------------------------- | ------------------------------------------------------------------------------------ |
| ⏳ ЖДУТ МОЁ РЕВЬЮ     | я ревьюер, head не ревьюнут             | —                                                                                    |
| 💬 ЖДУТ МОЙ ОТВЕТ     | ответили после меня / я автор с тредами | —                                                                                    |
| 🔀 ЖДУТ РЕ-РЕВЬЮ      | новые коммиты после моего ревью         | —                                                                                    |
| ✅ ЖДУТ АППРУВ/РЕЗОЛВ | осталось только моё действие            | —                                                                                    |
| 😴 ЖДУТ ДРУГИХ        | мяч не у меня                           | свёрнута; 🔥-бейдж активности «там что-то изменилось с прошлого визита» (2026-07-30) |

Пустая группа: **компактный вид, не скрывается** (решение 2026-07-30): однострочная
свёрнутая полоса «⏳ ЖДУТ МОЁ РЕВЬЮ — пусто» — полное отсутствие группы выглядело бы
как баг; явное «пусто» читается как честное состояние.

**Ответы на вопросы оператора:** «как ревьювер вижу, что мне ответили» — группа 💬 +
⏳N на карточке. «Что я должен сделать» — группа внимания + ⚙-строка. «Что нового, не
заходя» — 📬 + 🔀 на карточке.

## Экран 2. Лента МР (`#/mr/:ref`)

### 2.1 Шапка-информер

| Элемент                  | Вижу                                                  | Состояния                                                     | Взаимодействие                                                  |
| ------------------------ | ----------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------- |
| Идентичность             | роль · ref · заголовок · [GitLab ↗]                   | 🟦                                                            | 🖱 GitLab ↗                                                     |
| Состояния                | внимание · ✅n/m · 👁 · 🏗 · 💬 · 🔀 · 📬             | 🟢                                                            | —                                                               |
| Описание                 | первая строка + [ещё ▾]                               | 🟦                                                            | 🖱 развернуть                                                   |
| ⚡ быстрые действия      | текущее ожидание + кнопки                             | 🟢 только когда есть ожидание                                 | 🖱 → decision (💥 при accept: эффект)                           |
| 🔄 «обрабатываю N новых» | активная фон-работа по событиям (новые треды/коммиты) | 🟢 появляется при gitlab_event→задача, исчезает по завершении | отдельный индикатор в шапке (2026-07-30), дополняет План-виджет |

### 2.2 Механика ленты

- Порядок: по `lastActivity` виджета; bump только при новом содержимом.
- Разделитель «📬 Новое с прошлого визита» 🟢 (серверный lastReadAt).
- Скелетоны при первой загрузке; ошибка виджета = ❌+retry внутри него.

### 2.3 Виджет 🔍 «Находки» (циклический)

| Зона                  | Вижу                                                 | Состояния                           | Взаимодействие / 💥                                            |
| --------------------- | ---------------------------------------------------- | ----------------------------------- | -------------------------------------------------------------- |
| Сводка                | «фактчек N/M · углублено K · совпадений с чужими: J» | 🟢 обновляется по ходу              | —                                                              |
| Строка находки        | severity · краткое · file:line · ✔/⏳ проверки       | 🟢 ⏳ идёт фактчек → ✔/❌           | 🖱 развернуть → diff-note                                      |
| diff-note             | код с привязкой file:line                            | 🟦 ±12 строк контекста (2026-07-30) | 🖱 «в GitLab ↗» — ссылка на точную строку (2026-07-30)         |
| Действия над находкой | [📮][✏️][🗑][🔎][🌐][💬]                             | 🟢 disabled пока идёт её задача     | 🖱 → задача в очередь (⏳ мгновенно); 📮=💥 постинг при accept |
| Дедуп-состояния       | 🤝 совпадает · ⚡ инсайт к отвеченному               | 🟢                                  | 🤝 → 🖱 скрыть; ⚡ → 🖱 «👍+💬 инсайт» (💥)                    |
| Групповые действия    | [📮 выбранные][✅ фактчек всех][🌐 вширь]            | 🟢                                  | 💥 постинг — через decision                                    |

| Контроль                   | Эффект                | Гард                                    |

| ✏️ описание МР             | editDescription       | decision                                |
| 💬 мутация артефакта       | CAS-запись + снапшот  | очередь; конфликт = видимая ошибка      |
| ↩ отмена автодействия      | компенсирующий эффект | где VCS позволяет, иначе пометка        |

## ✅ Решено в интервью (2026-07-30)

1. Быстрые действия на карточке доски — **нет**: доска = чтение, действия внутри МР.
2. 📬 — число на карточке + hover-тултип с разбивкой по типам (🔍/💬/🦊).
3. diff-note — ±12 строк контекста + ссылка «в GitLab ↗» на точную строку.
4. «Обрабатываю новое» — отдельный 🔄-индикатор в шапке МР.
5. Пустые группы — не скрываются, а компактный вид с явным «пусто» (скрытие выглядит как баг).
6. 😴 ЖДУТ ДРУГИХ — 🔥-бейдж активности на свёрнутой группе.
7. ArtifactFullView — отдельный маршрут `#/mr/:ref/artifact/:path`.
8. Тултипы ревьюеров — да: имя, когда проголосовал/последняя активность.
